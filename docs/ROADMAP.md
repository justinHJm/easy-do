# easy-do 제품 로드맵

> 상태: 계획 합의본. 이 문서는 기능을 구현하거나 버전을 올리는 작업을 승인하지 않는다.
>
> 기준 버전: `0.2.1` (2026-09-17)

## 목표와 원칙

- 정식 Galaxy Store 출시는 `1.0.0`까지 유예한다.
- 계정, 클라우드 동기화, 웹은 하나의 사용자 경험이다. 로그인만 제공하거나, 휴대폰과 웹의 데이터가 따로 저장되는 상태로 웹을 공개하지 않는다.
- 기기 모델명 대신 앱이 실제로 사용할 수 있는 화면 너비를 기준으로 UI를 구성한다. 이렇게 하면 일반 휴대폰, 태블릿, Fold의 펼친 화면, 분할 화면, 웹에 함께 대응할 수 있다.
- 기존 기기 내 Todo는 보존한다. 클라우드 도입 때 새 데이터 구조로 옮기더라도 사용자가 만든 Todo를 잃지 않아야 한다.
- 마일스톤 기능은 완료 기준과 검증을 충족한 뒤에만 다음 버전으로 올린다. `1.0.0`은 별도 사용자 승인 후 진행한다.

## 현재 상태: 0.2.1

- Todo, 목록, 완료 이력, 반복 규칙, 프로필, 설정은 기기 내 저장소에만 저장된다.
- Android 홈 위젯은 같은 기기 내 저장소를 읽는다.
- 웹용 화면 구조는 있지만, 브라우저 저장소와 휴대폰 저장소가 동기화되지는 않는다.
- 앱 안의 의견 보내기는 Google Form으로 연결된다.

## 0.3.0: 반응형 UI와 튜토리얼

### 구현 순서

1. 반응형 화면 기반을 먼저 만든다.
2. 그 기반 위에 첫 실행 튜토리얼을 추가한다.

튜토리얼을 나중에 얹어야 화면 크기별 배치가 다시 깨지지 않는다.

### 화면 너비 규칙

| 화면 분류 | 기준 | 기본 화면 구성 |
| --- | --- | --- |
| 좁음 | 600dp 미만 | 현재와 같은 하단 탭, 한 열 Todo 목록 |
| 중간 | 600dp 이상 840dp 미만 | 왼쪽 탐색 영역과 오른쪽 Todo 목록의 2단 구성 |
| 넓음 | 840dp 이상 | 탐색 영역, Todo 목록, 필요 시 상세·통계 패널을 가진 넓은 구성 |

- Fold를 접은 화면과 일반 휴대폰은 좁은 화면 구성으로 처리한다.
- Fold를 펼친 화면과 태블릿은 실제 사용 가능한 너비에 따라 중간 또는 넓은 구성으로 처리한다.
- Flip의 외부 커버 화면은 기기·설정별 일반 앱 지원이 달라 별도 UI를 보장하지 않는다. 앱이 실행되는 경우 좁은 화면 구성으로 안전하게 표시한다.
- 가로 모드와 분할 화면도 동일한 너비 규칙을 사용한다.
- 위젯은 크기를 줄였을 때 항목 수와 글자 길이가 넘치지 않는 축소 표시 규칙을 별도로 검증한다.

### 튜토리얼 범위

- 첫 실행에만 표시한다.
- Todo 추가, 기한·반복, 위젯, 의견 보내기를 짧게 안내한다.
- 건너뛰기와 마이 화면의 `튜토리얼 다시 보기`를 제공한다.
- 완료 여부는 계정과 무관한 기기별 설정으로 저장한다.

### 완료 기준

- 좁은 휴대폰, 큰 휴대폰, Fold 펼침 또는 태블릿, 가로 화면에서 Todo·통계·마이·추가/수정 화면이 잘리지 않는다.
- 글자 크기를 키운 접근성 환경에서도 주요 조작이 가능하다.
- 첫 실행, 건너뛰기, 다시 보기의 동작이 일관된다.

## 0.4.0: 계정 연동과 클라우드 동기화

계정과 동기화는 분리 출시하지 않는다. 로그인만 되고 Todo가 기기 안에만 남으면 사용자가 기대하는 다른 기기 동기화가 제공되지 않기 때문이다.

### 구현 전에 확정할 결정

1. 최초 지원 로그인 방식: Android·웹 기준으로 Google 로그인을 우선 후보로 둔다. 다른 로그인 제공자는 이후 확장한다.
2. 클라우드 서비스와 운영 비용·관리 주체를 정한다.
3. 개인정보 처리 방침과 계정 삭제·데이터 삭제 방식을 정한다.
4. 동시에 같은 Todo를 수정할 때의 규칙을 정한다. 초기 방향은 Todo별 마지막 수정 우선이며, 삭제 기록을 보존해 삭제된 Todo가 다시 나타나지 않게 한다.

### 구현 범위

- 로그인 상태와 안전한 세션 저장.
- 기존 로컬 Todo를 계정 데이터로 옮기는 일회성 이전 과정.
- 오프라인 우선 사용: 기기에서 즉시 저장하고 연결 복구 때 동기화.
- Todo·목록·반복 완료 기록의 변경 시간, 고유 식별자, 삭제 기록 관리.
- 클라우드 변경을 받은 뒤 로컬 저장소와 Android 위젯을 새로고침.
- 로그아웃, 다른 계정 전환, 동기화 실패·재시도 화면.

### 완료 기준

- 휴대폰 두 대에서 같은 계정으로 로그인했을 때 Todo 추가·수정·완료·삭제가 반영된다.
- 인터넷 없이 만든 Todo가 연결 복구 후 사라지지 않는다.
- 기존 `0.2.1` 로컬 데이터가 이전 후에도 유지된다.
- 계정 전환 시 다른 계정의 Todo가 보이지 않는다.

## 0.5.0: 웹 버전

웹은 새 Todo 저장소를 만들지 않고 `0.4.0`의 로그인·클라우드를 그대로 사용한다.

- 휴대폰 앱과 같은 Todo, 목록, 통계, 마이, 의견 보내기를 제공한다.
- 넓은 화면에서는 탐색 영역과 목록을 함께 보이고, 좁은 브라우저에서는 휴대폰 구성으로 축소한다.
- 휴대폰에서 만든 Todo가 웹에, 웹에서 완료한 Todo가 휴대폰과 위젯에 반영되는 것을 핵심 검증으로 둔다.
- Android 홈 위젯은 웹 범위에 포함하지 않는다.

## 0.6.0: 시간 기한과 동기화 안정화

현재 기한은 날짜 전용(`YYYY-MM-DD`)이다. 계정·클라우드 데이터 이전과 시간 기한 변경을 한 번에 수행하지 않는다.

- 기존 날짜 전용 Todo는 그대로 보존한다.
- 시간이 지정된 Todo만 날짜와 시간을 함께 저장·표시한다.
- 앱에서는 정확한 시각, 위젯에서는 공간에 맞는 축약 표기를 사용한다.
- 당일에는 `n시간 남음` 같은 상대 표시를 검토한다.
- 시간대, 자정 경과, 여러 기기 동시 수정, 오프라인 대기열을 집중 검증한다.

## 1.0.0: 정식 출시 준비

- Galaxy Store 제출용 APK와 서명·버전·배포 정보를 검증한다.
- 정식 출시 결정과 `1.0.0` 버전 변경은 별도 승인 후 진행한다.
